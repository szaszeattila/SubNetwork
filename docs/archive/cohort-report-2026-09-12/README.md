# Original report reviewed in Zotero

These files preserve the edition used for the 11 questions answered on
2026-09-12, before the report was revised.

- `COHORT-REPORT.pdf`: unchanged original PDF, SHA-256
  `3a9624f60ebd04924256ab528dc1ecd78fc5e959ded2614acb22e69fb87aff37`.
- `COHORT-REPORT.md`: its original Markdown source.
- `zotero-annotations.json`: all 11 highlights, questions, page labels,
  coordinates and annotation keys from Zotero attachment `X69XURRV`.

The PDF and the annotation export are kept in the project's private repository
and are left out of the public copy (decided 2026-10-10): the export is the
reviewer's own questions, which the live report answers, and the PDF's links
are paths on the machine it was rendered on.

**The six relative links inside `COHORT-REPORT.md` do not resolve, and are left
that way on purpose** (noted 2026-09-17). They were written for a file sitting
at `docs/`, and this copy sits two directories deeper. Rewriting them would edit
a frozen snapshot to make a link checker happy, which is the wrong trade: the
point of this directory is that its contents are byte-for-byte what was
reviewed. Read the live document at [../../COHORT-REPORT.md](../../COHORT-REPORT.md),
and [../../INDEX.md](../../INDEX.md) for which documents are in force.

Zotero stores these annotations in its library database, not inside the PDF
bytes. The original Zotero attachment and library annotations were not
modified. The JSON is a separate preservation copy, not a claim that the
archived PDF has embedded highlights. Page references in the questions refer
to this 17-page edition; the revised report has different pagination.
