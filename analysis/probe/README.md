# The probe set

Read-only diagnosis of the similarity ranking. **Adopts nothing**, changes
nothing, and writes to neither database nor the viewer. The findings are in
[docs/SIMILARITY-DIAGNOSIS.md](../../docs/SIMILARITY-DIAGNOSIS.md).

This sits beside [analysis/similarity_harness/](../similarity_harness/README.md)
and answers a different question. The harness asks **how often** the ranking is
right, against a generated ATC answer key. This asks **where and why**, against
50 drug relationships written down by hand.

Hand-writing an answer key is what
[docs/SIMILARITY-HARNESS.md](../../docs/SIMILARITY-HARNESS.md) §3 refuses, and
the distinction is the reason this is allowed to exist. That refusal is about
*optimising*: hand-picking the key that judges six hand-picked constants lets
the grade be made to say anything. It does not apply to asking whether the
ranking is right about morphine and oxycodone, and what went wrong if not —
which the aggregate cannot answer, because a rate over 283 molecules never says
which 283. **So nothing here is ever summed into a number a constant is swept
against.** The runner prints that warning next to its own counts.

| file | what it does |
| --- | --- |
| `probes.mjs` | the 50 relationships: query, acceptable partners, why, and `kind` — `mechanism`, `opposite` (a *high* rank is the failure) or `nonN` (outside the answer key's reach) |
| `run.mjs` | asks the ranking about each one; `--detail N` and `--only NAME` add the diagnosis |
| `pair.mjs` | one pair, every shared target row, with actions, species and what D15 saw |
| `structure.mjs` | orthologue double-counting, screening-only pairs, and how much of the catalogue carries no curated direction |
| `direction_recovery.mjs` | prototypes reading curated direction at the protein rather than the target record, and counts what it would demote |
| `dump_atc.py` | every ATC code ChEMBL has for each cohort molecule, not only level N |
| `regrade.mjs` | the same ranking graded against three keys: N-only, all ATC, non-N |
| `atc_coverage.py` | what the build's `level1 = 'N'` filter keeps out of the key |
| `keystats.mjs` | what the current answer key is made of |

`atc_full.json` is generated by `dump_atc.py` and is an intermediate, not a
source. Everything else reads `viz/graph.data.js`, which is generated and
gitignored, and reports a missing payload rather than a bad grade when there is
no build to read.

```bash
node analysis/probe/run.mjs
node analysis/probe/pair.mjs MORPHINE NALTREXONE
python3 analysis/probe/dump_atc.py && node analysis/probe/regrade.mjs
```
